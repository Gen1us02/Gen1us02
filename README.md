#### 1. Модуль ТОиР на Go (стартап)
> **Период:** апрель 2026 – настоящее время  
> **Стек:** Go, PostgreSQL, gRPC, Docker, Kubernetes, Tilt  
> **Что сделано:** сервис управления объектами и оборудованием для ТОиР, сервис уведомлений, модели предметной области в PostgreSQL, описание proto-файлов, развёртывание в k8s.

#### 2. Интернет-магазин на Django
> **Период:** январь 2026 – февраль 2026  
> **Стек:** Django, PostgreSQL, OAuth, caching  
> **Что сделано:** wishlist, отзывы, разделение профилей пользователя и продавца, авторизация через Google, оптимизация кешированием.
> 
> 🔗 [Ссылка на репозиторий](https://github.com/RiviKiwi/RiviKiwiApp)

#### 3. Currency Converter API (FastAPI)
> **Период:** май 2026 – июнь 2026  
> **Стек:** FastAPI, SQLAlchemy, PostgreSQL, JWT, Docker Compose, pytest  
> **Что сделано:** регистрация и JWT-аутентификация, интеграция внешнего валютного API, тестирование (pytest-asyncio), контейнеризация.  
> 
> 🔗 [Ссылка на репозиторий](https://github.com/Gen1us02/Converter_API)

#### 4. Игра-аналог «Crimsonland» на Pygame
> **Период:** 2026
> **Стек:** Pygame, Python  
> **Что сделано:** 2D-шутер с видом сверху: проработан геймплей (движение, стрельба, волны врагов), система очков и здоровья, реализована физика пуль и врагов. Учебный проект по разработке игр.
> 
> 🔗 [Ссылка на репозиторий](https://github.com/Gen1us02/PPOIS_2/tree/lab3)

#### 5. GUI для работы с данными о студентах
> **Период:** 2026  
> **Стек:** PySide6 (Qt), SQLAlchemy, PostgreSQL, Python  
> **Что сделано:** десктопное приложение для управления студентами (CRUD операции, поиск, фильтрация), графический интерфейс на Qt, связь с БД через ORM. Демонстрирует навыки создания настольных приложений.
> 
> 🔗 [Ссылка на репозиторий](https://github.com/Gen1us02/PPOIS_2/tree/lab2)

#### 6. Веб-интерфейс на Django для управления роботом
> **Период:** 2026  
> **Стек:** Django, PostgreSQL, HTML/CSS  
> **Что сделано:** веб-панель для удалённого управления роботом (отправка команд, отображение телеметрии, логирование действий). Реализована интеграция с API робота, система авторизации, графики датчиков.
>
